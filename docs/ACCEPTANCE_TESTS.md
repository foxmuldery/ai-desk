# MVP 测试与验收清单

## A. 环境与安全
- [ ] Linksys MX5300 固件未改动。
- [ ] Coordinator 只监听预期的可信接口。
- [ ] 未授权手机无法创建任务。
- [ ] 未授权 Agent 无法注册或领取任务。
- [ ] 任务路径只能使用已登记的工作目录 ID。
- [ ] 手机请求不能执行任意 shell 字符串。
- [ ] 日志不包含 token、密码或 cookie。
- [ ] 高风险操作需要明确审批。

## B. 手机输入与提交
- [ ] S22 Ultra 可打开响应式界面。
- [ ] Typeless 可将口述指令填入任务输入框。
- [ ] 用户可修改识别文本。
- [ ] 可选择目标电脑和适配器。
- [ ] 双击提交或网络重试不会创建重复任务。
- [ ] 服务端未确认时，UI 显示未提交而不是已接收。
- [ ] 目标设备离线时给出明确提示。

## C. 单机执行闭环
- [ ] 创建任务后数据库有记录。
- [ ] 状态按 queued → accepted → running → terminal 变化。
- [ ] Agent 返回实际执行状态和结构化结果。
- [ ] 成功必须满足指定验收条件。
- [ ] 失败显示错误码与摘要。
- [ ] 进程中断时不伪报成功。
- [ ] 任务结果可从任务详情查询。

## D. 通知与 TTS
- [ ] 页面前台时状态可刷新。
- [ ] 成功、失败、需决策使用不同通知类别。
- [ ] 中文语音播报任务名称、目标电脑和结果摘要。
- [ ] 锁屏测试有真实设备记录。
- [ ] 省电模式/浏览器退出的限制有明确说明。
- [ ] 手机重新打开后可以恢复任务列表。

## E. 持久化与恢复
- [ ] Coordinator 重启后历史任务仍在。
- [ ] 重启后运行中的任务会进入核对状态。
- [ ] Agent 重启后可重新注册。
- [ ] 不会因心跳丢失自动将任务标记失败或成功。
- [ ] 非幂等任务不会自动无限重试。
- [ ] SQLite 备份与恢复过程经过验证。

## F. 多电脑
- [ ] 至少两台 Mac 能注册。
- [ ] 手机能指定目标电脑。
- [ ] 设备在线状态由心跳与最近活动计算。
- [ ] 忙碌节点的排队行为符合配置。
- [ ] 断线后任务状态正确。
- [ ] 每台机器只运行其被授权的适配器。

## G. 应用适配器
每个适配器分别验证：
- [ ] 参数校验。
- [ ] 权限校验。
- [ ] 允许目录约束。
- [ ] 超时。
- [ ] 取消行为。
- [ ] 成功/失败判断。
- [ ] 输出脱敏。
- [ ] 日志与可诊断性。
- [ ] 幂等策略。
- [ ] 单元与集成测试。
