# 安全与权限策略

## 威胁模型

AI Desk 能触发本机应用、访问项目文件和运行开发工具。主要风险包括：
- 未授权设备提交任务。
- 语音识别错误导致意外操作。
- Prompt injection 或恶意项目内容试图改变执行边界。
- 任意路径、命令、参数注入。
- 日志泄露密钥或个人文件。
- 网络中断造成重复执行或伪成功。
- 手机或节点失窃后继续拥有访问权。

## 网络

- Linksys MX5300 保持原厂固件。
- 默认仅绑定 127.0.0.1。
- 非 loopback 绑定必须同时配置至少 32 字符的 token、TLS 证书和私钥；缺任一项即拒绝启动。
- 证书应由手机信任；不应要求用户忽略浏览器证书警告。
- 实验性 Codex 执行器只允许 loopback 访问；启用它时拒绝非 loopback 服务绑定。\n- Codex 子进程只继承明确允许的少量环境变量，不继承 AI Desk bearer token 或其他无关 provider API Key。\n- 只读沙箱并不提供完整的机密隔离，第一阶段只能对无真实机密的独立测试仓库使用。\n- 不将 Coordinator API 直接暴露到互联网。
- 不依赖“知道一个端口”作为安全措施。
- 手机与每台 Agent 使用独立凭据；支持撤销和轮换。
- 远程访问若将来需要，优先另行设计 VPN 与强认证。

## 身份认证

- 手机 token 与 Agent token 分离。
- token 不写入仓库、前端 bundle、截图或普通日志。
- 生产 token 存在本机权限受限的配置或钥匙串中。
- 所有写请求进行认证、授权、输入校验和速率限制。
- 任务审批 token 必须短时有效、一次性使用，并绑定任务与动作摘要。

## 权限模型

- 默认只允许管理员配置的工作目录。
- 使用目录 ID，不接受远程任意绝对路径。
- 使用适配器 ID 和结构化参数，不接受任意远程 shell 字符串。
- 适配器按最小权限运行，默认不使用管理员/root。
- 只开放已登记的设备能力。
- 所有操作记录执行主体、目标设备、适配器、状态与结果摘要。

## 操作分级

### 低风险：可在用户预先允许后自动执行
- 读取允许目录中的文件元数据。
- 运行已登记的只读检查。
- 读取 Git 状态、测试报告。
- 生成新报告到指定输出目录。

### 中风险：默认需明确确认或项目级授权
- 修改文件。
- 运行可能改写工作区的脚本。
- 安装依赖。
- 创建 commit。
- 批量移动或重命名文件。

### 高风险：必须独立审批
- 删除数据或覆盖原始资产。
- push、发布、部署到生产环境。
- 对外发送消息、邮件或发布内容。
- 修改账号权限、系统安全设置。
- 购买、支付或其他不可逆外部动作。

## 输出与日志

- 不记录 token、密码、cookie、私钥。
- stdout/stderr 设置大小上限并做敏感信息过滤。
- 任务结果默认提供摘要和受控文件引用，而不是整段文件内容。
- 保留足够审计信息调查任务失败，并设定合理的日志保留期限。

## 可靠性安全

- 任务必须先持久化再回报已接收。
- 使用幂等键防止重复提交。
- 对执行中断任务先核对状态，不能直接重跑。
- 状态未知时显示 unknown，不标记 succeeded。
- 取消操作需记录是否真正停止底层执行。
- 服务关闭、更新和备份都应有明确恢复流程。

## 公开仓库注意事项

当前 GitHub 仓库是公开仓库。只能提交通用代码、示例配置和已脱敏文档。不要提交个人 IP、局域网真实拓扑、真实项目路径、token、账号信息、私有素材或机器唯一标识。真实部署配置应留在本机并加入 .gitignore。
