# 安全与权限策略

## 威胁模型

AI Desk 能触发本机应用、访问项目文件和运行开发工具。主要风险包括：
- 未授权设备提交任务。
- 语音识别错误导致意外操作。
- Prompt injection 或恶意项目内容试图改变执行边界。
- 任意路径、命令、参数注入。
- 日志泄露密钥或个人文件。
- 网络中断造成重复执行或伪成功。
- 手机或节点失窃后继续拥有访问权。

## 网络

- Linksys MX5300 保持原厂固件。
- 默认仅绑定 127.0.0.1。
- 非 loopback 绑定必须同时配置至少 32 字符的 token、TLS 证书和私钥；缺任一项即拒绝启动。
- 证书应由手机信任；不应要求用户忽略浏览器证书警告。
- 不将 Coordinator API 直接暴露到互联网。
- 不依赖“知道一个端口”作为安全措施。
- 手机与每台 Agent 使用独立凭据；支持撤销和轮换。
- 远程访问若将来需要，优先另行设计 VPN 与强认证。

## 身份认证

- 手机 token 与 Agent token 分离。
- token 不写入仓库、前端 bundle、截图或普通日志。
- 生产 token 存在本机权限受限的配置或钥匙串中。
- 所有写请求进行认证、授权、输入校验和速率限制。
- 任务审批 token 必须短时有效、一次性使用，并绑定任务与动作摘要。

## 权限模型

- 默认只允许管理员配置的工作目录。
- 使用目录 ID，不接受远程任意绝对路径。
- 使用适配器 ID 和结构化参数，不接受任意远程 shell 字符串。
- 适配器按最小权限运行，默认不使用管理员/root。
- 只开放已登记的设备能力。
- 所有操作记录执行主体、目标设备、适配器、状态与结果摘要。

## 操作分级

### 低风险：可在用户预先允许后自动执行
- 读取允许目录中的文件元数据。
- 运行已登记的只读检查。
- 读取 Git 状态、测试报告。
- 生成新报告到指定输出目录。

### 中风险：默认需明确确认或项目级授权
- 修改文件。
- 运行可能改写工作区的脚本。
- 安装依赖。
- 创建 commit。
- 批量移动或重命名文件。

### 高风险：必须独立审批
- 删除数据或覆盖原始资产。
- push、发布、部署到生产环境。
- 对外发送消息、邮件或发布内容。
- 修改账号权限、系统安全设置。
- 购买、支付或其他不可逆外部动作。

## 输出与日志

- 不记录 token、密码、cookie、私钥。
- stdout/stderr 设置大小上限并做敏感信息过滤。
- 任务结果默认提供摘要和受控文件引用，而不是整段文件内容。
- 保留足够审计信息调查任务失败，并设定合理的日志保留期限。

## 可靠性安全

- 任务必须先持久化再回报已接收。
- 使用幂等键防止重复提交。
- 对执行中断任务先核对状态，不能直接重跑。
- 状态未知时显示 unknown，不标记 succeeded。
- 取消操作需记录是否真正停止底层执行。
- 服务关闭、更新和备份都应有明确恢复流程。

## 手机试验的额外安全边界（2026-10-25）

手机入口必须与 Mac Studio 本机真实 Codex 适配器分离。本分支使用 `AI_DESK_EXECUTION_PROFILE=phone-dry-run`：

- 只允许 Coordinator 绑定 `127.0.0.1`（或其它明确的 loopback）、使用至少 32 字符的随机访问令牌，拒绝同时启用 `AI_DESK_ENABLE_CODEX_READONLY=1`。
- `POST /api/v1/tasks` 只接受 `adapter=dry-run` 和目录 ID `demo`；任何真实 Codex、shell 或未知执行器均返回 `EXECUTION_PROFILE_BLOCKED`。
- 后台 worker 再次检查 Profile；如果重启恢复的历史队列中存在其它适配器，会标记为失败并记录 `policy.blocked`，绝不执行。
- 手机任务列表和任务/事件详情只返回 `dry-run` 记录，避免错误指向其它执行器的数据库时泄露敏感指令或执行摘要。
- 不相信 `X-Forwarded-For`、`X-Real-IP`、客户端可伪造的 `Host` 或其它代理头作为授权依据。
- 手机入口只允许通过私有 Tailscale **Serve** + TLS，**禁止 Funnel**、公网端口映射、明文远程 HTTP、禁用证书验证。Tailnet ACL 和 HTTPS 只负责传输与设备成员访问，不能替代 AI Desk 强随机 Bearer Token。
- 令牌仅保存在浏览器当前页面内存、由 Mac Studio 启动终端手动提供；不放入 URL、LocalStorage、Git、截图或普通日志。
- 终端与 SQLite 中的任务指令仍属于敏感数据；默认只运行无敏感内容的测试指令，测试结束后按数据保留策略清理。手机锁屏/后台播报不属于本阶段已验证能力。

**注意**：`127.0.0.1` 并不能单独证明请求来自 Mac Studio 用户，因为 Tailscale Serve 会代理远程请求到本机 loopback。真正的执行权限由明确的 Profile 和 adapter allowlist 控制；不能把已经开启真实 Codex 的 Coordinator 直接复用给手机。

## 公开仓库注意事项

当前 GitHub 仓库是公开仓库。只能提交通用代码、示例配置和已脱敏文档。不要提交个人 IP、局域网真实拓扑、真实项目路径、token、账号信息、私有素材或机器唯一标识。真实部署配置应留在本机并加入 .gitignore。
